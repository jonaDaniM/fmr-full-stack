How the estimated time-saved metric is calculated

FMR: 17.30 seconds per package, 33.36 seconds per selected ISO, 20 seconds per normal material row, and 26 seconds when a description exceeds 52 characters.

Pipe footage: 34.66 seconds per package plus 8 seconds per selected ISO—6 seconds to copy and paste the ISO number and 2 seconds to type its total footage.

The model is based on measurements from a technically proficient operator. Email/PDF access, downloading, command preparation, machine wait time, final review, and corrections are excluded. Only the newest successful result per package and workflow contributes to the headline.
